# Just Cancel It

A small browser game about dark patterns.

In 2019 you started a free trial of Glimmr+, a streaming service you've opened twice. You've been paying $14.99 a month ever since. Today you cancel it. Every trick you fall for gets added to your bill.

**[Play it here](https://YOUR-USERNAME.github.io/just-cancel-it/)**

## What's inside

Twelve levels covering real dark patterns used by apps and websites:

1. The lure: honest screens that teach you to trust the big pink button
2. Trick questions and confirmshaming
3. Pre-selected cookie consent
4. Roach motel: easy to join, hidden cancel link
5. Nagging retention offers and misleading button labels
6. Disguised ads
7. Bait and switch
8. Sneak into basket, false urgency and drip pricing
9. Friend spam and notification nagging
10. Obstruction: a close button that runs away
11. Forced friction: blocked pasting and sabotaging autocorrect

The end screen shows what you were charged and explains each pattern.

## Running it

It's one self-contained HTML file with no build step. Open `index.html` in any browser.

Glimmr+ is a fictional company.
